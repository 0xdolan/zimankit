# Glossary

| term | Kurdish | meaning |
|---|---|---|
| bizroke | بزرۆکە | the unwritten short high vowel of Sorani (/ɯ/, Latin `i`) |
| ezafe | îzafe / ئیزافە | linking suffix between a noun and its modifier (`mala min`, `ماڵی من`) |
| oblique case | rewşa çemandî | non-subject case of Kurmanji nouns/pronouns (`-ê`, `-î`, `-an`, `min`) |
| direct case | rewşa navkî | citation/subject case |
| split ergativity | — | ergative alignment in past tenses of transitive verbs only |
| enclitic pronoun | جێناوی لکاو | `م ت ی مان تان یان` in Sorani |
| preverb | pêşlêker | separable verbal prefix (`hil-`, `ra-`, `هەڵ`, `دا`) |
| present / past stem | rehê dema niha / borî | the two lexical verb stems |
| transitive / intransitive | gerguhêz / negerguhêz | |
| gender | zayend: mê (f), nêr (m) | Kurmanji only |
| definite / indefinite | binavkirî / nebinavkirî | |
| ZWNJ | نیوەبۆشایی | U+200C, prevents joining without a space |
| G2P | — | grapheme-to-phoneme conversion |
| LID | — | language identification |
| UPOS | — | Universal Dependencies part-of-speech tags |
| lemma | — | citation form (infinitive for verbs) |
| sonority | — | relative loudness; governs cluster legality |
| epenthesis | — | insertion of a vowel to repair a cluster |
| Hawar | — | the Latin alphabet of Kurmanji (1932) |
| subject | kirde / بکەر | who or what does the action; `nsubj` |
| object | bireser / بەرکار | what the action is done to; `obj` |
| head, dependent | — | in a dependency structure, each word (the dependent) hangs from one other word (its head) |
| root | — | the word that heads the whole sentence: the main verb or the predicate |
| deprel | — | dependency relation: the label on the link from a head to a dependent |
