# Learn Kurdish: Sorani and Kurmanji from zero

Two complete, self-paced courses for people who know **no Kurdish at all**:

| course | script | spoken mainly in | start here |
|---|---|---|---|
| **Central Kurdish (Sorani, `ckb`)** | Arabic-based alphabet, right to left | Başûr / Southern Kurdistan (Kurdistan Region of Iraq: Erbil, Sulaymaniyah), Rojhilat / Eastern Kurdistan (in Iran) | [Sorani course](ckb/README.md) |
| **Northern Kurdish (Kurmanji, `kmr`)** | Latin (Hawar) alphabet, left to right | Bakur / Northern Kurdistan (in Turkey), Rojava / Western Kurdistan (in Syria), Behdînan (Duhok), the diaspora | [Kurmanji course](kmr/README.md) |

The two are close relatives. They share most core vocabulary (*ziman* / *زمان* “language”, *av* / *ئاو* “water”) and the same big idea in the past tense (ergativity), but they differ in script, gender, case and many endings. Learn one first. If you later add the other, every Kurmanji lesson has a matching Sorani lesson with the same number and topic, so you can compare them side by side.

## Levels

Every lesson is tagged with a level. Each level builds on the previous one, so **everyone starts at lesson 1**:

| tag | you will be able to… | lessons |
|---|---|---|
| 🟢 **Beginner** | read and write the alphabet, pronounce words, say who and what things are, use nouns, *this/that*, adjectives and the present tense | 1–10 |
| 🟡 **Intermediate** | talk about possession, wishes and commands, the past (including ergativity), places and comparisons | 11–17 |
| 🔴 **Advanced** | use every tense and the passive, compound verbs, irregular verbs, clitic placement and the written standard | 18–23 |

Learning paths:

* **Just the basics** → lessons 1–10 of one course.
* **Conversational** → lessons 1–17.
* **Complete** → lessons 1–23, plus the reference pages (every verb conjugated, every noun declined, vocabulary).

## How the lessons are made

The prose of each lesson is written by hand. **Every table of forms is generated by zimankit**: conjugations, noun endings, IPA pronunciations, syllables, the other-script spelling and morphological analyses. Each lesson file contains small generator blocks (`<!-- gen:… -->`); `python scripts/gen_tutorials.py` fills them in from the same code the toolkit uses, and the test suite fails if a lesson ever disagrees with the code.

This has two consequences:

1. The tables are consistent: a rule is applied the same way in every lesson and every reference page.
2. If you find a wrong form in a table, the toolkit's rule is wrong, not just the page. Please report it, because fixing the rule fixes every page and the grammar checker built on it.

## Conventions used in every lesson

| symbol | meaning |
|---|---|
| **bold** Kurdish | the form being taught |
| <sub>small text</sub> under a form | the same word in the other script (Latin for Sorani, Arabic script for Kurmanji), then IPA |
| /…/ | pronunciation in the International Phonetic Alphabet; `(ɯ)` is a vowel you say but do not write |
| 1sg, 2sg, 3sg, 1pl, 2pl, 3pl | I, you (one person), he/she/it, we, you (several), they |
| * before a sentence | an ungrammatical example, shown so you can recognise the mistake |
| <details> “Answers” | click to reveal the answers to the practice exercises |
