| | |
|---|---|
| infinitive | **دەستپێکردن** (destpêkridin) /dæstpeːkɾ(ɯ)d(ɯ)n/ |
| meaning | to begin |

| past stem | **کرد** |
| transitivity | transitive — ergative in past tenses |
