# هەڵبژاردن — to elect, to choose; election

| | |
|---|---|
| infinitive | **هەڵبژاردن** (hellbijardin) /hæɫb(ɯ)ʒaːɾd(ɯ)n/ |
| meaning | to elect, to choose; election |
| present stem | **بژێر** |
| past stem | **بژارد** |
| transitivity | transitive — ergative in past tenses |
| preverb | **هەڵ** |
